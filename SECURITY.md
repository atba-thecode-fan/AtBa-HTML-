# Security Policy

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security vulnerability in this project, please report it responsibly.

### How to Report

Please **do not** open a public GitHub issue for security vulnerabilities. Instead:

1. Email your security concerns to the repository maintainers
2. Include the following details in your report:
   - Description of the vulnerability
   - Steps to reproduce (if applicable)
   - Potential impact
   - Suggested fix (if you have one)

### Responsible Disclosure

We appreciate your effort to responsibly disclose your findings and will make every effort to:

- Respond to your report within a reasonable timeframe
- Work with you to understand and resolve the issue
- Provide appropriate credit for the disclosure (if desired)

### Supported Versions

Please check the release notes to see which versions are currently supported with security updates.

## Security Best Practices

When using this project, please follow these security best practices:

- Keep your dependencies up to date
- Review the code before deploying to production
- Report any suspicious activity or vulnerabilities promptly

## Thank You

Thank you for helping keep this project and its users safe!
